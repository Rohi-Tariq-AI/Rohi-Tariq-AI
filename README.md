Research Software

Partitioning Graph Clustering With User-Specified Density

A reproducible Python software implementation of my published partitioning graph-clustering algorithm.

The algorithm begins with graph triangles as initial cluster structures and expands clusters while monitoring a user-selected relative density. The software provides:

User-specified target density
Non-overlapping cluster discovery
Structured CSV and JSON results
Mean Relative Density Deviation Coefficient (MRDDC)
Recorded-edge coverage
Unclustered-node reporting
Automated reproducibility tests
Deterministic cluster visualization
My broader graph-clustering research also includes an edge-based algorithm for partitioning and overlapping clustering. The current software release implements the partitioning algorithm.
